1. Bootstrap 3 CSS (namespaced and modified)
   Copyright (c) 2011-2015 Twitter, Inc.
   Licence:  MIT
   Source:   https://github.com/twbs/bootstrap/tree/v3.3.4
   Files:    themes/starter/css/bootstrap.css
             themes/starter.hero/css/bootstrap.css
             themes/starter.designers/css/bootstrap.css
             themes/starter.hero.designers/css/bootstrap.css
             public/assets/css/libs/bootstrap-modals.css
   Status:   modified. These are derivatives of the Bootstrap 3.x stylesheet
             (the closest upstream release is 3.3.4) in which every selector
             is prefixed with ".arlo#arlo" or ".arlo-bootstrap-modal" so that it
             only affects Arlo markup, with some declarations customised.
             bootstrap-modals.css contains only the modal-related excerpt.
             The exact upstream version of the original is not recorded.
             Bootstrap CSS includes normalize.css (see entry 2).
   Pinned:   kept at the Bootstrap 3 release the bundled Starter themes were
             written against. Bootstrap 3 is end of life, and later major
             versions rename classes and change markup, as Bootstrap's
             migration guides describe, so the themes' markup and stylesheets
             would have to be rewritten. Only the stylesheets are bundled, not
             Bootstrap's JavaScript. The advisories published for Bootstrap 3
             (CVE-2016-10735, CVE-2018-14040, CVE-2018-14042, CVE-2018-20676,
             CVE-2018-20677, CVE-2019-8331 and CVE-2024-6485) all concern its
             JavaScript plugins (collapse, tooltip, popover, affix and button
             handling), so none applies to the stylesheets.

7. Font Awesome 4.7.0 and the Arlo icon compatibility fonts
   Copyright 2016 Dave Gandy ("Font Awesome by Dave Gandy - http://fontawesome.io")
   Licence:  fonts SIL Open Font License 1.1 (see below); CSS MIT
   Source:   https://fontawesome.com/v4/license/
             https://github.com/FortAwesome/Font-Awesome/tree/v4.7.0
   Files:    public/custom-assets/font-awesome-4.7.0/
   Status:   unmodified Font Awesome 4.7.0 distribution files.
   Pinned:   4.7.0 is the final Font Awesome 4 release. Later versions have
             breaking changes: the icon syntax changes (for example fa fa-user
             becomes fas fa-user), some icons are renamed and the font files

             Stylesheets written for earlier Arlo themes, in existing
             deployments, rely on the 4.7.0 glyphs and class names (see the
             compatibility fonts below). No published advisory was found for
             4.7.0.

   Arlo icon compatibility fonts
   Files:    public/custom-assets/arlo-icon-compat/starter-glyphs.woff2
             public/custom-assets/arlo-icon-compat/block-glyphs.woff2
   Status:   glyph subsets cut from the Font Awesome 4.7.0 font
             (fontawesome-webfont.ttf) and registered under the font family
             names used by earlier Arlo themes, so that customer stylesheets
             written for those themes keep working. They contain no other
             artwork and remain under the SIL Open Font License 1.1.

   Arlo icon stylesheets
   Files:    admin/assets/css/arlo-icons.css
             themes/*/css/arlo-icons.css
             themes/*/css/fonts.css
             themes/be.software.designers/css/arlo-web-controls.css
   Status:   stylesheets written by Arlo. They map class names to glyphs of the
             Font Awesome 4.7.0 font (loaded from the font files above) and
             to Arlo-authored SVG shapes. Each file names Font Awesome 4.7.0 in
             its header comment.
